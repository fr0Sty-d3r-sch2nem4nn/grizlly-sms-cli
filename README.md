## Grizzly-CLI

<center>
<img src="./grizzly-cli-logo.png" width=200 height=200 />
</center>

A cli-tool for generating activation numbers for services, managing the account balance and activating numbers from [GrizzlySMS](https://grizzlysms.com) service.


### Why to build it ?

- quicker access to the data you're interested in like e.g. price for a number of a specific country for a service you're interested in (instead of scrolling you provide data and get immediate output)
