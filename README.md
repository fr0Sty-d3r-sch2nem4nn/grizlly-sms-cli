## Grizzly-CLI

<center>
<img src="./grizzly-cli-logo.png" width=200 height=200 />
</center>

A cli-tool for generating activation numbers for services, managing the account balance and activating numbers from [GrizzlySMS](https://grizzlysms.com) service.


### Why to build it ?

- quicker access to the data you're interested in like e.g. price for a number from a specific country for a service you're interested in (instead of scrolling you provide specific arguments and get immediate output and even detailed response)

### Why would one use grizzly-cli ?

`grizzly-cli` tool has been build to facilitate browsing for the best deals for the service
you are interested in. This tool can provide you detailed informations like the vendors offers and amount of phone numbers, which you can then specify while requesting a phone number.
